# Security policy

Report vulnerabilities in this layer's metadata privately by email to Ahmed Adel Wafdy
<fandes99@gmail.com>. Do not open a public issue.

Report vulnerabilities in Autoware, ROS 2 or other packages to their upstream projects.
This layer only packages them, and fixes reach it when its recipes are regenerated or
their pinned revisions are bumped.

This is a community project with no response-time commitment. It is not safety-certified
and is not intended for use on public roads.
